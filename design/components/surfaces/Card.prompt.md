The base Atempo surface — flat espresso with a hairline and no drop shadow; `emphasis` encodes tempo.

```jsx
<Card emphasis="active">…in-tempo row…</Card>
<Card emphasis="flat">…steady row…</Card>
<Card emphasis="cold">…cold row…</Card>
<Card emphasis="hero" padding={32}>…recap…</Card>
```

Never add a box-shadow — depth comes from layered espresso + hairlines. Shadow belongs only to the floating window frame.
