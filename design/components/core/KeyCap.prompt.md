Hairline mono cap for a keyboard shortcut hint (e.g. the command-palette affordance). Faint, low-emphasis.

```jsx
⌕ jump to project · run · resume <KeyCap>⌘K</KeyCap>
```

`KeyCap` is only for shortcut hints in command bars / palettes — for a stack label use `Tag`, for status use `Badge`. Keep the glyphs functional Unicode (⌘ ⌥ ⇧ ↵), never emoji.
